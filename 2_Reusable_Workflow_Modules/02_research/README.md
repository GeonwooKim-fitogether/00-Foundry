# Module: research

> Placeholder (v0.1.0).

## Purpose
Gather evidence needed to make the next decision — no more, no less.

## Inputs
- Open questions from `01_problem-framing` or from a current `NPI_Brief.md`.

## Outputs
- Findings note (per question: claim + evidence + confidence + source).
- Updates to `NPI_Brief.md` where evidence changes the framing.

## Acceptance Criteria
- Each open question has a yes/no/inconclusive answer with cited evidence.
- "Inconclusive" entries state what would resolve them.

## Control Points
Start (questions agreed) → Automated (source coverage check) → Human if Critical → Final (questions answered or explicitly deferred).

## Checklist
- [ ] Questions stated as questions, not topics
- [ ] Each finding has a source
- [ ] Confidence level recorded

## Anti-patterns
- Open-ended literature dumps with no decision attached.
- Citing without quoting the specific claim used.
