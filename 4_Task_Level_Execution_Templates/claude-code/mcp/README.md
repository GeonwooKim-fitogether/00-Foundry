# MCP — External System Connectors

MCP (Model Context Protocol) servers give Claude Code typed access to external systems: file stores, browsers, issue trackers, schedulers, custom internal tools.

## Files
- `mcp-connection-policy.md` — what to connect, when, and the safety rules.

## Status (v0.1.0)
- **No MCP servers are implemented or configured here.**
- Policy is documented so future projects on this Factory connect external systems consistently.
