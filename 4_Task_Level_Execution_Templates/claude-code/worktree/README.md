# Worktree

A **Worktree** is a parallel production line: a separate working copy on its own branch with one clear purpose. Worktrees let Claude Code run independent experiments or features in parallel without polluting the integration baseline.

## Files
- `worktree-policy.md` — when to create, name, and close worktrees.

## Status (v0.1.0)
- Policy documented.
- No automation (e.g., scripted worktree creation) in this version.
